Smart Snippets: UI design

Design mockups for the Windows desktop snippet utility described in the requirements specification. The popup is fully interactive: type to filter, use the arrow keys and Enter, switch layout and sort, and add a snippet.

Assumptions carried over from the spec: single-level folders, plain-text snippets, text sizes 12 / 14 / 18, and a default hotkey of Ctrl+Shift+Space.

Global popup

Opens centered on the monitor of the target window, with the search box focused and the first result selected. The add button opens the editor over the popup and keeps the original insertion target.
