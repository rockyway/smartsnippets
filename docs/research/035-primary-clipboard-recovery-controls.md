## Scope limits

Restoration preserves every captured supported original representation byte plus
the declared current run marker and three zero-valued protective metadata formats;
it is not identical original format-set restoration. The original text never left
RAM or entered application logs.

The refusal control changes **HWND ownership within the same guardian process**,
not an arbitrary foreign process producer. Unknown/changed external owners remain
refused. No focus transfer, hotkey registration, Ctrl+V, Enter, Copy commit or usage
recording was reachable in these control scenes. Positive native execution still
requires its separately reviewed capability/input/keyboard-retention gates and
truthful source/artifact equivalence before row-6 attestation.
